# ☕ Java Collection Framework Codes

A collection of Java programs demonstrating the concepts of the Java Collection Framework. This project contains examples of commonly used collection classes, interfaces, and utility operations.

## 📚 Topics Covered

- ArrayList
- LinkedList
- Vector
- Stack
- Queue
- Deque
- HashSet
- TreeSet
- HashMap
- LinkedHashMap
- TreeMap
- Hashtable
- Iterator
- ListIterator
- Comparable
- Comparator
- BitSet
- Properties
- Java Streams
- Collection Operations (Union, Intersection, Difference)
- Remove Duplicates
- Word Frequency
- Second Largest Element

## 🛠 Technologies Used

- Java
- Java Collection Framework
- Eclipse IDE / IntelliJ IDEA

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Compile and run any Java file to explore the corresponding collection example.

## 🎯 Learning Objectives

- Understand Java Collection Framework interfaces.
- Learn List, Set, Queue, and Map implementations.
- Practice sorting using Comparable and Comparator.
- Perform collection operations like Union, Intersection, and Difference.
- Explore Java Stream API examples.
